<original_problem_statement>
The initial goal was to build an Android chat app, TEAFRIENDS, similar to Slack. Core features included detailed user profiles with professions, user search (#singer), and 1-on-1/group chats.

This was significantly expanded by a new feature request: a TeaCoins wallet system.
- **Wallet & Currency**: Users have a wallet with TeaCoins. New users are credited with 100 TeaCoins upon joining.
- **Marketplace**: Users can order tea from designated sellers within the app.
- **Seller Role**: Users can apply to become a seller. An admin must approve these requests. Sellers can create a menu of items they sell.
- **Ordering Flow**:
    1. A user places an order for tea.
    2. The seller receives a notification for the new order.
    3. The seller fulfills the order.
    4. The buyer confirms the delivery in their app.
    5. Upon confirmation, 1 TeaCoin is automatically transferred from the buyer's wallet to the seller's wallet.
- **Admin Role**: A designated admin user (Kummar Sambhav) needs a dashboard to approve seller applications.
- **UI/UX**: The user requested a professional-looking UI using brand colors, with a dedicated Wallet tab in the main navigation.
</original_problem_statement>
