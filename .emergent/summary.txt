<original_problem_statement>
The project is an Android chat app, TEAFRIENDS. The initial goal was to build a social layer on top of an existing chat and e-commerce application.

Feature set requested during this session:
1.  **Friend/Follower System:** Originally an Instagram-style follow system, the user requested a change to a Facebook-style **two-way friend request system** (send request -> accept/decline).
2.  **Global Chat Enhancements:**
    *   Implement **@mentions** that highlight the user's name and notify them.
    *   Implement a **reply-to-message** feature, similar to WhatsApp.
3.  **Reels Section:**
    *   A new tab for a TikTok/Instagram-style vertical video feed.
    *   Users can upload videos from their gallery or record a new one (up to 60 seconds).
    *   Videos should be compressed on the backend using a powerful tool like FFmpeg.
    *   Users can set visibility to public or friends-only.
    *   Users can like and comment on reels.
4.  **Enhanced Profile:**
    *   Instead of just a number, the profile page should display the user's friends with their avatars in a tappable list/modal.
5.  **Bug Fixes:**
    *   Fix the automatic order notification sound for sellers. (This was de-prioritized by the user in favor of new features).
