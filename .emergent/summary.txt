<original_problem_statement>
The project is an Android chat app, TEAFRIENDS. Initially a Slack clone, it evolved to include a TeaCoins wallet and marketplace system where users can buy/sell tea. An admin (Kummar Sambhav) approves seller applications.

The latest set of feature requests introduces a comprehensive privacy and social layer:
1.  **Follower System**: Implement an Instagram-style, one-way follow system.
2.  **Message Requests**: Non-followers can send an initial message, but it must be accepted by the recipient from a Message Requests screen before a full chat conversation can begin.
3.  **Profile Stats**: User profiles should display their follower and following counts.
4.  **Global Chat**: A new, separate screen for a public chat room where all users can converse, similar to a Discord channel.
5.  **Audio Notifications**: Add sound effects for new order notifications (for sellers) and for sending/receiving chat messages.
